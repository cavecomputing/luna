# Luna macOS menu bar icon

Use `LunaTemplate.png` and keep `LunaTemplate@2x.png` beside it. The `Template` suffix tells macOS and Electron to treat the artwork as a monochrome template image that automatically adapts to light and dark menu bars.

- `LunaTemplate.png` — 16 × 16 standard Electron/macOS tray icon
- `LunaTemplate@2x.png` — 32 × 32 Retina companion
- `LunaTemplate-18.png` — optional 18 × 18 version
- `LunaTemplate-18@2x.png` — optional 36 × 36 Retina companion
- `LunaTemplate.svg` — editable vector master
- `LunaFoxMoonTemplate.png` and `LunaFoxMoonTemplate@2x.png` — optional branded fox-moon alternative
- `LunaFoxMoonTemplate.svg` — editable vector master for the branded alternative

The PNGs contain black artwork on a transparent background.
